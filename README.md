# Система создания электронных приглашений

## Назначение

Приложение предназначено для создания электронных приглашений
на различные события и обработки ответов приглашённых гостей.

## Целевая аудитория

Пользователи, которым необходимо организовать мероприятие
и отправить приглашения гостям.

## Предметная область

Система позволяет создавать события, формировать приглашения,
указывать данные гостей и фиксировать ответы на приглашения.

## Основные сущности

- Событие
- Приглашение
- Гость
- Ответ

## Основные функции

- Проверка корректности данных события.
- Формирование электронного приглашения для гостя.
- Обработка ответа гостя на приглашение.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных;
- создание системы регистрации пользователей;
- создание и редактирование событий;
- управление списком гостей;
- отправка электронных приглашений;
- сохранение ответов гостей;
- разработка REST API;
- контейнеризация приложения;
- настройка CI/CD.
