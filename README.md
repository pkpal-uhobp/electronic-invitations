# Система создания электронных приглашений

Учебный индивидуальный проект по дисциплине «Технологии разработки
приложений на базе фреймворков». Версия репозитория соответствует этапу ПР2.

## Назначение

Приложение предназначено для создания событий, формирования электронных
приглашений и хранения ответов гостей. Проект продолжает сценарий ПР1: функции
проверки события, формирования текста приглашения и обработки ответа сохранены,
но теперь приложение работает с коллекциями данных, несколькими модулями и
JSON-файлами.

## Возможности ПР2

- создание и просмотр нескольких событий;
- поиск событий по названию и сортировка по дате;
- создание электронных приглашений для гостей;
- проверка, можно ли создать активное приглашение тому же гостю на событие;
- отмена приглашений;
- сохранение ответа гостя: `да`, `нет`, `не знаю`;
- поиск и сортировка приглашений;
- подсчёт статистики по ответам и отменённым приглашениям;
- загрузка и сохранение данных в JSON;
- обработка ошибок ввода и файлов;
- автоматические тесты `pytest`.

## Структура проекта

```text
electronic-invitations/
├── main.py
├── events.py
├── invitations.py
├── storage.py
├── utils.py
├── requirements.txt
├── data/
│   ├── events.json
│   └── invitations.json
└── tests/
    ├── test_events.py
    ├── test_invitations.py
    └── test_storage.py
```

- `main.py` — точка запуска и консольное меню;
- `events.py` — проверка, добавление, поиск и сортировка событий;
- `invitations.py` — создание, отмена и обработка приглашений и ответов;
- `storage.py` — чтение и запись JSON через контекстный менеджер `with`;
- `utils.py` — безопасный ввод чисел и дат;
- `data/` — данные приложения;
- `tests/` — автоматизированные тесты.

## Формат данных

События хранятся в `data/events.json` как словарь. Ключ — идентификатор
события, значение — словарь с названием и датой.

```json
{
  "1": {
    "name": "День рождения",
    "date": "2026-10-15"
  }
}
```

Приглашения хранятся в `data/invitations.json` как список словарей.

```json
[
  {
    "id": "1",
    "event_id": "1",
    "guest_name": "Анна",
    "response": "не знаю",
    "status": "active"
  }
]
```

## Использованные возможности Python

В проекте применяются списки и словари, циклы `for` и `while`, функции,
модули, исключения, JSON-файлы, контекстные менеджеры, генератор в
`iter_upcoming_events()` и `lambda`-функции для сортировки. Основные функции
снабжены аннотациями типов и docstring.

Классы и объекты на этапе ПР2 не используются.
