# Фактическая проверка подготовленного архива

Выполнено в среде сборки:

- `python -m compileall -q .` — синтаксическая компиляция всех `.py` прошла.
- `python -m db.import_json` — исходная SQLite ПР7 создана из JSON, 2 пользователя, 3 гостя, 2 события, 3 приглашения.
- Последовательное выполнение **всех 19 SQL-запросов** из исходного слоя ПР7 — успешно.
- `pytest -q tests/test_console_legacy.py tests/test_pr7_sql.py` — **4 passed** (только тесты, не требующие Django).
- SQLite `PRAGMA integrity_check` и `PRAGMA foreign_key_check` — см. вывод проверок при сборке.

Не выполнялось в среде сборки:

- `python manage.py check`, `migrate`, `showmigrations`, `pytest -v` со всеми ORM-тестами, `flake8` — **Django и flake8 в этой среде не установлены, а доступ к пакетному репозиторию недоступен**.
- Поэтому нельзя честно утверждать, что Django-приложение проверено запуском. В архив включены миграции и тесты, которые следует выполнить у себя после `pip install -r requirements.txt`.
- Действительные Git-коммиты и завершение внешнего курса Яндекс Практикума не создавались.
