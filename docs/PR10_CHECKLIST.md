## Отличия от примера Roomly

В Roomly бронирование занимает помещение на дату. Здесь активное приглашение исключает **гостя** из списка доступных для **конкретного события**. Статус `completed` не присваивается автоматически по дате; его ставит администратор. Для `GeneratedField` используется длина названия события, а не признак помещения `capacity >= 50`. Эти отличия необходимы, чтобы сохранить предметную область проекта.
