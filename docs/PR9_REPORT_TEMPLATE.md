## Доработка индивидуального проекта

Созданы модели `User` (организатор), `Guest`, `Event`, `Invitation`. У события — nullable связь на организатора (`SET_NULL`), у приглашения — обязательная связь на событие (`CASCADE`) и nullable связь на гостя (`SET_NULL`). Настроены `related_name`, `choices`, `DateField`.

Структура целевой базы управляется миграциями в `users_web`, `guests_web`, `events_web`, `invitations_web`. Данные ПР7 переносятся из `data/invitations.sqlite` командой `manage.py import_pr7` в одной транзакции с сохранением первичных и внешних ключей.

Представления используют ORM: получение списков и отдельных объектов, `filter`, `exclude`, `Q`, поиск, сортировку, `select_related`, `values`, `aggregate`, `annotate`, `Count`, пагинацию. Сохранены страницы событий, приглашений, гостей, организаторов, поиска по дате, свободных гостей и статистики; добавлены фильтры и навигация между страницами приглашений.
